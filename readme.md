# The Information Button!

The information button brings you from an original wikipedia page (the city of Arlon by default in seed.txt and init_info.sh) to another one by following a random link found on that page. It then keeps doing that everytime you press the button, starting from the previously reached page.
-
The command to run the button is: npm run info
-
You can check what came out of it for me in the [history](https://github.com/pierrecoric/the_information_button/blob/main/output/history.md) and you can also read some [info](https://github.com/pierrecoric/the_information_button/blob/main/output/some_info.md).
